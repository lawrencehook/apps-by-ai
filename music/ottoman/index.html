Ottoman saz semâîsi

The saz semâîsi is an instrumental form in the Ottoman classical repertoire. These three openings use aksak semâî, a rhythmic cycle of ten eighth notes. Each row below lasts one cycle. A long first note can occupy two pulses while a run of short notes fits inside one.

Playback uses a synthesized plucked tone and a common listening tempo. Pitch follows the transcription’s 53 divisions of the octave, with written La4 set to 440 Hz.
