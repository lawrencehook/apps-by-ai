Confidence intervals & tests

Express sampling uncertainty without confusing the data with the hypothesis.

Before this LLN, CLT & concentration, Estimation & likelihood

X¯±z1−α/2σnnormal data, known σ
DefinitionsTheoremsApplicationsExercises 2

Definitions

01

Confidence procedure

A random interval C(X) with coverage Pθ(θ∈C(X))≥1−α for the specified model and parameter range.

02

Null hypothesis and p-value

A p-value is, under the null model, the probability of a test statistic at least as extreme as the observed one in the specified tail or tails.

03

Type I error and power

Type I error rejects a true null. Power is the rejection probability at a specified alternative.

Key theorems

01

Normal mean interval

For iid N(μ,σ²) data with known σ, the displayed interval has exact coverage 1−α. With unknown σ and n≥2, replace σ by s and the normal quantile by a tₙ₋₁ quantile.

02

Union bound for testing

Testing m true null hypotheses each at level α/m gives probability of at least one false rejection at most α, without an independence assumption.

Notable applications

01

Experiments

Intervals show plausible effect sizes and precision; tests quantify incompatibility with a chosen null.

02

Multiple comparisons

Multiplicity corrections help control error when examining many hypotheses.

Watch the assumptions

  • A frequentist 95% confidence statement concerns repeated-sample coverage, not a 95% posterior probability for the fixed parameter.
  • A p-value is not the probability that the null hypothesis is true. Statistical significance is not effect size.

Work it out

Try before revealing

01 / Compute

For normal data with known σ=10, n=100, and X̄=50, give a 95% confidence interval for μ.

Hint

Use z₀.₉₇₅≈1.96.

Solution

The standard error is 1, so the interval is [48.04,51.96].

02 / Compute

What per-test level gives a Bonferroni family-wise level of 0.05 for 20 tests?

Hint

Divide the family-wise level by the number of tests.

Solution

Use 0.05/20=0.0025 for each test.
